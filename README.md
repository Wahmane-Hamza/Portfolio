# Hamza Wahmane — Portfolio

A high-performance modern developer portfolio website built with **React**, **Vite**, and **Tailwind CSS**, designed with a futuristic dark tech aesthetic inspired by 1337 Coding School (42 Network).

---

## ⚡ Tech Stack

- **Framework:** [React 18](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Inter & Fira Code / JetBrains Mono

---

## 🚀 Features

- **Futuristic Dark Aesthetic:** Slate-900 background with glowing cyan and emerald accents.
- **1337 / 42 School Pedigree:** Highlights peer-to-peer engineering, Unix systems, and memory management achievements.
- **Interactive Terminal CLI (`./hamza_cli`):** Simulated interactive bash terminal allowing visitors to run commands (`help`, `about`, `skills`, `projects`, `1337`, `github`, `linkedin`, `clear`).
- **Interactive Projects Gallery:** Filter projects by category (*Full-Stack*, *Systems & C/C++*, *Interactive / Games*) with instant search.
- **Direct Profiles:** Direct links to LinkedIn (`https://www.linkedin.com/in/hamza-wahmane-8318493b5/`) and GitHub (`https://github.com/Wahmane-Hamza`).
- **One-Click Contact:** Copy-to-clipboard email action and direct message mailto form.
- **Fully Responsive:** Tailored for mobile, tablet, and desktop viewports.

---

## 🛠️ Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
```
The output will be generated inside the `dist/` directory, ready to deploy to **Vercel**, **Netlify**, or **GitHub Pages**.
